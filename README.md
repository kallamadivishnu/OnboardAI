# 🚀 OnboardAI

An AI-powered Employee Onboarding Platform that automates hiring, employee registration, document verification, onboarding progress tracking, analytics, and AI-assisted reporting.

## 🌐 Live Demo
https://onboardai-platform.streamlit.app

## ✨ Features

- 🔐 Secure Login Authentication
- 👨‍💼 Candidate Hiring
- 📝 Employee Registration
- 📂 Personal Details Management
- 📄 Resume Upload
- 🪪 ID Verification
- 📷 Photo Upload
- 📊 Onboarding Progress Tracker
- 🤖 AI Candidate Score
- 📈 HR Analytics Dashboard
- 📑 Automated PDF Report Generation

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Requests
- FPDF
- JSON Database
